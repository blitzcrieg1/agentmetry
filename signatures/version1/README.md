# CLA signatures (ICLA v1.0)

Individual contributor signatures are recorded in `cla.json` in this directory on
the **`cla-signatures`** branch, not on `master`.

Until 2026-11-16 the [CLA Assistant](https://github.com/contributor-assistant/github-action)
workflow wrote them. That action is archived and stopped starting, so the
workflow was removed and the maintainer now adds each signature by hand, linking
the pull request comment in which the contributor signed. The steps are in
[CONTRIBUTING.md](../../CONTRIBUTING.md#maintainer-checking-the-cla).

- **CLA text:** [CLA.md](../../CLA.md) (version 1.0)
- Edit `cla.json` only to add a signature that exists as a comment on a pull request.

When CLA v2.0 is published, a new directory `signatures/version2/` will be used;
existing v1 signatures remain valid for contributions made under v1.
